🛒 GroceryGo

Online Grocery Shopping & Delivery Management System
GroceryGo is a modern online grocery shopping and delivery management web application designed to make grocery ordering simple, fast, and organized.
It combines the customer shopping experience with admin and delivery operations in one platform.

Frontend

The current academic version uses Browser Local Storage and Session Storage for application data and login sessions.
